# diont17.github.io

Personal homepage for `dionthomas.nz`, built as a static Jekyll site for GitHub Pages.

The layout is a local adaptation of the Minimal Light direction, with added support for normal pages and blog posts.

## Editing

- Homepage content: `index.md`
- About page: `about.md`
- Now page: `now.md`
- Blog index: `blog.md`
- Posts: `_posts/YYYY-MM-DD-title.md`

Each post should use front matter like:

```yaml
---
title: "Post Title"
date: 2026-05-30
excerpt: "Short summary for the blog index."
---
```
